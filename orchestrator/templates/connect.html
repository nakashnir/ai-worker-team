How to Connect

EvalOps runs evaluation tasks against LLM models, stores results in PostgreSQL, and surfaces them through this dashboard. Submit tasks via the REST API or use the form in this UI.

{# ── What the system does ── #}

What EvalOps Supports

  • Task queue architecture — Submit tasks via API; workers poll Redis and execute asynchronously
  • Multi-provider LLM evaluation — Anthropic Claude (primary) and OpenAI (fallback) with retry logic
  • Deterministic scorers — exact_match, contains_expected, format_nonempty
  • LLM-as-judge — Rubric-structured judge evaluator with failure taxonomy classification
  • Persistent storage — Run-level and sample-level results stored in PostgreSQL
  • Nightly regression checks — GitHub Actions workflow with baseline comparison and webhook alerts
  • Read-only dashboard — Browse, search, compare evaluation runs
{# ── Step-by-step ── #}

Quick Start

Step 1: Prepare a JSONL dataset file in shared/datasets/.
Step 2: Submit an eval.run task with your model, scorers, and dataset path.
Step 3: Poll GET /task/status/{task_id} until status is done.
Step 4: View results in the dashboard at /dashboard or via API.

Example: Dataset Row

{"id": "s001", "prompt": "What is 2+2?", "expected": "4", "metadata": {"category": "math"}}

Example: Eval Task Payload

{
  "description": "Nightly regression eval",
  "task_type": "eval.run",
  "inputs": {
    "dataset_path": "datasets/nightly_eval_curated_v1.jsonl",
    "model": "anthropic:claude-sonnet-4-5-20250929",
    "scorers": ["exact_match", "contains_expected", "format_nonempty"]
  }
}

Example: Eval with LLM Judge + Rubric (optional)

{
  "description": "Quality evaluation with judge",
  "task_type": "eval.run",
  "inputs": {
    "dataset_path": "datasets/nightly_eval_curated_v1.jsonl",
    "model": "anthropic:claude-sonnet-4-5-20250929",
    "scorers": ["exact_match"],
    "evaluator": "llm_judge",
    "rubric": [
      {
        "key": "answer_quality",
        "label": "Answer Quality",
        "description": "Does the response answer the question accurately?",
        "weight": 2.0,
        "required": true
      }
    ]
  }
}

Example: Using curl

# Submit task
curl -sf -X POST http://127.0.0.1:8080/task/submit \
  -H "Content-Type: application/json" \
  -d '{"description":"My eval","task_type":"eval.run","inputs":{"dataset_path":"datasets/nightly_eval_curated_v1.jsonl","model":"anthropic:claude-sonnet-4-5-20250929","scorers":["exact_match"]}}'

# Poll status (replace TASK_ID from response above)
curl -sf http://127.0.0.1:8080/task/status/TASK_ID

# Fetch results
curl -sf http://127.0.0.1:8080/eval/run/TASK_ID
